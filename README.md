# Бот обучения и допуска агентов

Каркас без контента: логика шагов уже реализована, видео/скрипты/вопросы тестов — заглушки в `training.yaml`.

## Логика (как договорились)

`/start` → «Приступим к обучению?» → видео 1 (презентация работы) → тест →
видео 2 (мини-курс) → тест → скрипт 1 → скрипт 2 → скрипт 3 → скрипт 4 →
тест по 4 скриптам (нужно 3 верных из 4) → «Вы уверены, что готовы приступать?» →
- «Да» → авто-выдача ссылок в 3 чата + уведомление Рашиду
- «Нет» → прогресс сбрасывается, обучение начинается заново с видео 1

Если тест не сдан — бот сразу даёт его пересдать (retry), не блокируя кандидата навсегда.

## Запуск на хостинге

```bash
pip install -r requirements.txt
cp .env.example .env   # вписать реальный BOT_TOKEN
python bot.py
```

Бот использует long polling (не нужен вебхук/домен). Для постоянной работы держите процесс
через systemd/pm2/screen — как обычно на вашем хостинге.

## Как загрузить видео прямо в чат (а не ссылкой)

1. Пропишите в `training.yaml` (`admission.admin_chat_id`) свой личный Telegram user id —
   это тот же id, что нужен для уведомлений о новых агентах.
2. Отправьте боту в личку сам видеофайл **как файл, без сжатия** (важно — см. ниже почему),
   не как обычное видео-сообщение.
3. Бот ответит `file_id` — скопируйте его в `training.yaml` в поле `video_file_id`
   нужного ролика.
4. Поле `url` можно оставить как запасной вариант — используется, только если
   `video_file_id` пустой.

Файл загружается на серверы Telegram один раз, дальше рассылается кандидатам мгновенно,
без повторной загрузки.

### Почему именно «как файл», а не «как видео»

Если отправить видео боту обычным способом (прикрепить как видео/из галереи), Telegram
**на стороне вашего телефона/компьютера** сжимает его перед отправкой — и на некоторых
исходниках это ломает пропорции кадра (было 16:9, стало похоже на 4:3). Бот теперь и
показывает кандидатам, и просит присылать видео через `send_document`/как файл — это
передаёт файл один в один, без пережатия.

Как отправить «как файл» в Telegram:
- **Телефон**: скрепка (📎) → выберите **«Файл»** (а не «Галерея»/«Видео») → найдите
  видео через проводник телефона.
- **Десктоп**: перетащите файл в чат — появится окошко предпросмотра с галочкой
  «Сжать изображения и видео» — **снимите** галочку перед отправкой.

Если пришлёте по-старому (сжатым видео-сообщением), бот предупредит об этом и всё равно
покажет `file_id`, но пропорции могут быть испорчены — лучше сразу переслать как файл.

## Что обязательно донастроить в `training.yaml`

- Видео (`video_file_id`, см. выше) или ссылки (`url`) на ролики.
- Тексты/ссылки 4 скриптов (`script_1`…`script_4`).
- Вопросы тестов и `correct_index` (индекс правильного варианта, с нуля).
- `admission.chats` — `chat_id` двух групп (см. ниже, как узнать).
- `admission.rashid_contact` — что показать агенту («по всем вопросам звоните...»).

## Как бот сам узнаёт chat_id ваших чатов

Добавьте бота **@AMeducation_bot** в каждый из 3 чатов как обычного участника
(через «Добавить участника» → найти по юзернейму), затем сделайте админом с правом
«Invite users via link» (нужно для авто-выдачи ссылок кандидатам). Как только бот
окажется в чате, он сам пришлёт вам в личку сообщение с `chat_id` этого чата —
останется скопировать его в `training.yaml`.

Канал (`https://t.me/AMonline13`) уже определился автоматически через API —
его `chat_id` = `-1004470495286`, уже вписан в конфиг. Для рабочего чата и базы
(приватные, только по инвайт-ссылке) — добавьте бота вручную, как описано выше.

## Важно про автодобавление кандидатов в чаты

Telegram-боты не могут молча добавить пользователя в группу без его действия (ограничение
самого Telegram, не бота). Поэтому механизм такой: бот создаёт одноразовую пригласительную
ссылку (`member_limit=1`) и присылает её кандидату — тот сам нажимает и вступает.
Для этого **бот должен быть админом** во всех трёх чатах с правом «Invite users via link».

## Хранение данных

Простой SQLite (`candidates.db`, создаётся автоматически рядом с ботом) — кто на каком шаге,
статус, результаты тестов с числом попыток. Не требует отдельной БД на хостинге.
